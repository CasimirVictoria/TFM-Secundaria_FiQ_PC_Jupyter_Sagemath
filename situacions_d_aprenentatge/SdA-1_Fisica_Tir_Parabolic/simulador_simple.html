🐍 Fase 1: Deducció Simbòlica de la Trajectòria (SageMath / Python)
Quadern Jupyter • Nucli SageMath 10.x sagemath_trajectoria.py 
# 1. Definició de variables simbòliques
var('t, x, y, v_0, alpha, g')

# 2. Equacions paramètriques de moviment
eq_x = x == v_0 * cos(alpha) * t
eq_y = y == v_0 * sin(alpha) * t - (1/2) * g * t^2

# 3. Aïllar el temps simbòlicament a partir de x(t)
sol_t = solve(eq_x, t)[0].rhs()   # t = x / (v_0 * cos(alpha))

# 4. Substitució de t(x) en y(t) -> Equació de la Trajectòria
y_trajectoria = eq_y.rhs().subs(t=sol_t).simplify_trig()

# 5. Càlcul de l'Abast Màxim X_max quan y(x) = 0
sols_x = solve(y_trajectoria == 0, x)
X_max = sols_x[1].rhs().simplify_trig()  # X_max = (v_0^2 * sin(2*alpha)) / g

# 6. Càlcul de l'Altura Màxima h_max (dy/dx = 0)
dy_dx = diff(y_trajectoria, x)
x_hmax = solve(dy_dx == 0, x)[0].rhs()
h_max = y_trajectoria.subs(x=x_hmax).simplify_trig()
Pas 1 • Aïllar el Paràmetre Temps
\[ t(x) = \frac{x}{v_0 \cos\alpha} \] Aïllament algebraic exacte del temps a partir del moviment uniforme en l'eix horitzontal.
Pas 2 • Equació de la Trajectòria
\[ y(x) = x \tan\alpha - \frac{g}{2 v_0^2 \cos^2\alpha} x^2 \] Deducció de la funció parabòlica \(y = f(x)\) eliminant la dependència temporal.
Pas 3 • Punts Singulars Deduïts
\[ h_{\text{màx}} = \frac{v_0^2 \sin^2\alpha}{2g}, \quad X_{\text{màx}} = \frac{v_0^2 \sin(2\alpha)}{g} \]
