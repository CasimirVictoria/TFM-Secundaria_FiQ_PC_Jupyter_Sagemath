Entorn integrat d'aprenentatge de Caixa Blanca: formulació estadística de Maxwell-Boltzmann, integració simbòlica i exploració dinàmica en temps real.

💡 Fonamentació Pedagògica: La temperatura és la manifestació macroscòpica de l'energia cinètica mitjana de les molècules (\(\langle E_c \rangle = \frac{3}{2} k_B T\)). Amb SageMath, l'alumnat calcula simbòlicament la velocitat més probable (\(v_{\text{mp}}\)) derivant la distribució de Maxwell-Boltzmann i obté la velocitat quadràtica mitjana (\(v_{\text{rms}}\)) mitjançant càlcul integral. Després, comprova visualment els xocs elàstics a la cambra interactiva.
🐍 Fase 1: Deducció Simbòlica i Estadística (SageMath / Python)
Quadern Jupyter • Nucli SageMath 10.x sagemath_termodinamica.py 
# 1. Variables simbòliques i hipòtesis físiques
var('v, M, R, T')
assume(M > 0, R > 0, T > 0)

# 2. Distribució de probabilitat de Maxwell-Boltzmann
f(v) = 4*pi * (M / (2*pi*R*T))^(3/2) * v^2 * exp(-M*v^2 / (2*R*T))

# 3. Velocitat Més Probable (v_mp): Maximització df/dv = 0
df = diff(f(v), v)
sols = solve(df == 0, v)
v_mp = sols[1].rhs()   # v_mp = sqrt(2 * R * T / M)

# 4. Velocitat Quadràtica Mitjana (v_rms): Càlcul Integral 
mean_v_sq = integrate(v^2 * f(v), v, 0, infinity)
v_rms = sqrt(mean_v_sq) # v_rms = sqrt(3 * R * T / M)

# 5. Energia Cinètica Mitjana per molècula ()
# m = M / N_A  i  k_B = R / N_A
Ec_mean = (1/2) * (M/N_A) * mean_v_sq  #  = (3/2) * k_B * T

# 6. Pressió Cinètica per Xocs a la Paret: P = (1/3) * (N * m *  / V)
Pas 1 • Funció de Distribució \(f(v)\)
\[ f(v) = 4\pi \left(\frac{M}{2\pi R T}\right)^{3/2} v^2 e^{-\frac{M v^2}{2 R T}} \] Probabilitat que una molècula tinga un mòdul de velocitat entre \(v\) i \(v+dv\).
Pas 2 • Màxim de la Corba (Derivada)
\[ \frac{df(v)}{dv} = 0 \implies v_{\text{mp}} = \sqrt{\frac{2 R T}{M}} \] Velocitat corresponent al pic màxim de la distribució estadística.
Pas 3 • Valor Eficaç i Energia (Integral)
\[ v_{\text{rms}} = \sqrt{\langle v^2 \rangle} = \sqrt{\frac{3 R T}{M}}, \quad \langle E_c \rangle = \frac{3}{2} k_B T \]
